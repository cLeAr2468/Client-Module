ANO ITO?
--------
Cascading dropdown system para sa Philippine addresses.
Kapag pumili ng Province, lalabas lang yung Municipalities sa province na yun.
Kapag pumili ng Municipality, lalabas lang yung Barangays sa municipality na yun.

EXAMPLE:
1. Select Province: "Leyte"
   → Lalabas lang: Tacloban, Ormoc, Baybay, San Jorge, etc.

2. Select Municipality: "San Jorge"  
   → Lalabas lang: Buenavista, Calapi, Crossing, Guintagbucan, etc.

3. Select Barangay: "Poblacion 1"
   ✅ Complete address!


PAANO I-INTEGRATE SA FORM
--------------------------

STEP 1: Import the component
-----------------------------
import AddressSelector from "@/components/common/AddressSelector";


STEP 2: Add sa state variables
-------------------------------
const [form, setForm] = useState({
  province: "",
  municipality: "",
  barangay: "",
  // ... other fields
});


STEP 3: Replace yung old address inputs
----------------------------------------
DELETE:
  <Input id="province" value={form.province} onChange={handleChange} />
  <Input id="municipality" value={form.municipality} onChange={handleChange} />
  <Input id="barangay" value={form.barangay} onChange={handleChange} />

REPLACE WITH:
  <AddressSelector
    province={form.province}
    municipality={form.municipality}
    barangay={form.barangay}
    onProvinceChange={(value) =>
      setForm({ ...form, province: value, municipality: "", barangay: "" })
    }
    onMunicipalityChange={(value) =>
      setForm({ ...form, municipality: value, barangay: "" })
    }
    onBarangayChange={(value) => 
      setForm({ ...form, barangay: value })
    }
    required={true}
    layout="grid"
  />


IMPORTANT NOTES!
----------------
⚠️ IMPORTANTE: Kapag nag-change ng Province, dapat i-reset yung Municipality at Barangay!
   onProvinceChange={(value) =>
     setForm({ ...form, province: value, municipality: "", barangay: "" })
   }

⚠️ IMPORTANTE: Kapag nag-change ng Municipality, dapat i-reset yung Barangay!
   onMunicipalityChange={(value) =>
     setForm({ ...form, municipality: value, barangay: "" })
   }

✅ Barangay lang, no need to reset anything:
   onBarangayChange={(value) => 
     setForm({ ...form, barangay: value })
   }


LAYOUT OPTIONS
--------------
layout="grid"    → 2 columns (Province & Municipality side by side, Barangay below)
layout="stacked" → 1 column (Lahat stacked, one below the other)

COMMON PROBLEMS & SOLUTIONS
----------------------------

PROBLEM: Barangay field is disabled
SOLUTION: Siguraduhing may selected na Province at Municipality

PROBLEM: Walang lumalabas na barangays
SOLUTION: Check kung may data sa philippineAddresses.js. Kung wala, mag-show ng text input.

PROBLEM: Hindi nag-u-update yung values
SOLUTION: Make sure naka-reset yung dependent fields:
  onProvinceChange={(value) =>
    setForm({ ...form, province: value, municipality: "", barangay: "" })
  }
